# 朱雀检测记录

每篇每版测完记一行。目的是让规则靠真实分数校准，不是靠猜。攒够几篇之后回头看：哪个改动真的动了分数。

测法：`node scripts/zhuque-check.mjs 稿子.md --json 朱雀-vN.json`（API，逐块打分）。统计行来自 `node scripts/text-stats.mjs 稿子.md --raw 素材.md --log`。

读数：网页版显示的"AI 率"对应 API 的 `labels_ratio`（AI + 疑似占比）。`softmax` 是整篇置信度，纯人写文本 0.000–0.05。**目标：人 100% 且 softmax < 0.1 且每块 conf < 0.1。**

## 对照实验：同一段文字改一个变量（v1 第 3 块，原版 conf 0.636）

| 变体 | 改了什么 | 朱雀 |
|---|---|---|
| 原版 | 直引号 + 一句一引号 + 记者式串词 | 疑似 100%，softmax 0.584 |
| C 去对称 | 只删"一半…另一半""我数了十三条""库特菌是大坝本地人。" | 疑似 100%，0.535（没用） |
| F 弯引号 | 只把 `"` 换成 `“”`，一字不改 | 人 100%，0.201 |
| D 去引号 | 只删掉所有引号 | 人 100%，0.074 |
| E 口语串 + 引号 | 原话揉进逗号长句，夹碎念，保留弯引号 | 人 100%，0.061 |
| B 口语串 | 同 E，不加引号 | 人 100%，0.025 |
| A 纯实录 | 时间戳 + 原话 + 弹幕，无串词 | 人 100%，0.047 |

结论：直引号是强特征；"一句一引号 + 串词"格式是次强特征；删对称无效。
