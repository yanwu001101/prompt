# 朱雀检测记录

每篇每版测完记一行。目的是让规则靠真实分数校准，不是靠猜。攒够几篇之后回头看：哪个改动真的动了分数。

测法：`node scripts/zhuque-check.mjs 稿子.md --json 朱雀-vN.json`（API，逐块打分）。统计行来自 `node scripts/text-stats.mjs 稿子.md --raw 素材.md --log`。

读数：网页版显示的"AI 率"对应 API 的 `labels_ratio`（AI + 疑似占比）。`softmax` 是整篇置信度，纯人写文本 0.000–0.05。**硬线：人 100% 且每块 label=0（块 conf 压到 0.35 以下有余量）。softmax < 0.1 是参考值，不为它牺牲可读性**（2026-09-12 第二轮实测，见下）。脚本从 2026-09-12 起只测末尾 `---` 以上的正文，交付说明不计分。

## 对照实验：同一段文字改一个变量（v1 第 3 块，原版 conf 0.636）

| 变体 | 改了什么 | 朱雀 |
|---|---|---|
| 原版 | 直引号 + 一句一引号 + 记者式串词 | 疑似 100%，softmax 0.584 |
| C 去对称 | 只删"一半…另一半""我数了十三条""库特菌是大坝本地人。" | 疑似 100%，0.535（没用） |
| F 弯引号 | 只把 `"` 换成 `“”`，一字不改 | 人 100%，0.201 |
| D 去引号 | 只删掉所有引号 | 人 100%，0.074 |
| E 口语串 + 引号 | 原话揉进逗号长句，夹碎念，保留弯引号 | 人 100%，0.061 |
| B 口语串 | 同 E，不加引号 | 人 100%，0.025 |
| A 纯实录 | 时间戳 + 原话 + 弹幕，无串词 | 人 100%，0.047 |

结论：直引号是强特征；"一句一引号 + 串词"格式是次强特征；删对称无效。

## 对照实验二：可读性改动各值多少分（2026-09-12，贱徐稿整篇）

用户说第一轮的稿子"不像公众号文章，缺少可读性"之后做的。每版只动一类东西，其余不变。

| 版本 | 改了什么 | 朱雀 | 最高块 |
|---|---|---|---|
| v5 | 第一轮口语串稿（无引号、11 个长段） | 人 100%，0.149 | 0.426（**是文末待审段**） |
| v6 | 加可读性：短段 + 空行 + 6 处冒号引导 + 成对短句金句 + 书面腔动词 | 疑似 12% 人 88%，0.351 | 0.517（待审段） |
| v7 | v6 去掉冒号、去掉成对金句、去掉写作腔，保留短段空行；脚本开始跳过待审段 | 人 100%，0.142 | 0.204 |
| v8 | v7 的开头逗号长句拆成三句句号短句 | 人 100%，0.205 | 0.330（就是这个开头） |
| v9 | v7 + 3 处关键原话加弯引号 | 人 100%，0.164 | 0.282 |
| v10 | v9 + 结尾那句"这枚徽章画面能证明的就是…"改口语 | 人 100%，0.164 | 0.309 |
| v11 | v10 + 开头换回逗号串写法 + 删掉编的个人经历 | 人 100%，0.138 | 0.177 |
| v12 | v11 换直播间视角，投稿元信息挪出正文 | 人 100%，0.244 | 0.372（结尾块） |
| v14 | v12 删总结式收尾 + 弹幕段去排比枚举 | 人 100%，0.226 | 0.337（结尾块） |

视角这一改整篇 softmax 从 0.138 涨到 0.226，但涨的全在结尾块（弹幕争论 + 收尾），开头块反而 0.177 → 0.115。硬线（人 100%、每块 label=0）没破，所以视角照用户要求走，不为 0.09 的分差换回解说腔。

单变量读数：

- 不测文末交付说明：0.425 → 0.142（同一篇字没动）。v2–v5 每版最高的那块都是待审段，之前一直在错怪正文。
- 3 处弯引号：+0.022，标签不变。
- 逗号长句拆成句号短句：+0.126，最贵的一个改动。
- 冒号引导 + 成对金句 + 书面腔：+0.209，还掉出人 100%。
- 短段落 + 空行 + 一行段：0（31 段的 v7 比 11 段的 v5 分还低）。

结论：可读性不是靠句号和排版换来的分数损失，真正涨分的是书面腔（冒号、金句、修饰性动词）和把口语逗号流切成短句。
