# 去 AI 味规则表

## 识别特征

| 类型 | 典型表现 | 处理方向 |
|------|----------|----------|
| 套路开场 | 在这个快速发展的时代、随着 AI 的发展、众所周知 | 删除铺垫，直接进入问题或场景 |
| 生硬连接 | 综上所述、基于此、由此可见、鉴于上述 | 改成自然承接，或直接删除 |
| 空洞大词 | 卓越、革命性、颠覆性、重要意义、巨大价值 | 用事实、数据、场景、结果替代 |
| 假金句 | 句子很响，但没有新信息 | 删掉，或改成具体判断 |
| 内容空心 | 每句话单看都通顺，合起来却没有主线、证据、细节或推进 | 先补结构和信息增量，再改词句 |
| 破折号滥用 | A——B、观点——解释、概念——定义 | 改用冒号、逗号、句号、括号，或重排句式 |
| 模板对立句 | 不是 A，而是 B | 直接说 B，或写成递进关系 |
| 空泛对立句 | 不是关于速度，而是关于可用性；不是基础设施，而是架构 | 如果 A/B 都抽象，改成具体对象、动作和判断 |
| 复杂排比 | 不仅 A，而且 B，更 C | 拆成短句，保留真正重要的信息 |
| 三件套节奏 | 连续使用三点式列表、三连形容词、三个并列动词 | 保留必要枚举，打破默认三连节奏 |
| bullet 堆叠 | 每段都是列表，像 AI 总结 | 必要列表保留，其余改成自然段 |
| 乱加粗 | 每段都有加粗，重点过多 | 只保留真正影响理解的关键词 |
| 翻译腔 | 语序像英文，抽象名词多，动作词少 | 用自然中文重说，重心前置 |
| 名词贫血 | 稳健且结构清晰、富有洞见、全面深入，但读者不知道具体指什么 | 补具体名词、对象、材料和动作 |
| AI 高频词 | nuanced、delve、robust、insightful；复杂微妙、深入探索、稳健、富有洞见 | 不做机械禁用，先判断是否真的有信息量 |
| 判词腔 | 用“不是免费的 X 来源”“必须看起来 Y”这类负向定义、制度化判断表达观点 | 改成更直接的判断、动作句或带人味的说法 |
| 资料味 | 元信息、背景、定义堆在开头 | 元信息后置，正文先开讲 |
| 讲义味 | 每段像定义，标题过于整齐 | 加入阅读牵引和轻微节奏变化 |

## 高频替换

| AI 味表达 | 更自然的处理 |
|-----------|--------------|
| 综上所述 | 所以 / 总的来说 / 直接说结论 |
| 鉴于此 | 因为这样 / 这也意味着 |
| 不难发现 | 删除，直接陈述 |
| 值得一提的是 | 删除，直接说 |
| 众所周知 | 删除，或补具体证据 |
| 具有重要意义 | 具体说明“对谁有什么用” |
| 这无疑是 | 删除“无疑”，用事实支撑 |
| 在这个快速发展的时代 | 直接进入具体问题 |
| 随着技术不断发展 | 说明具体变化是什么 |
| 让我们一起 | 改成具体行动或直接收束 |
| 深入探索 / delve into | 直接说要分析什么，或删除 |
| 复杂微妙 / nuanced | 写清楚到底复杂在哪里、分歧在哪里 |
| 稳健 / robust | 换成具体能力、约束或测试结果 |
| 富有洞见 / insightful | 写出那条洞见本身 |

## 内容空心和结构问题

AI 味最难处理的地方，通常不是某个词，而是“看起来都对，但读完没留下东西”。这类稿子不能只做词语替换，要先处理主线。

典型特征：

- 每个句子单独看都顺，合起来却没有明确判断。
- 段落之间只是并列摆放，没有因果、递进、转折或取舍。
- 形容词多，具体名词少；读者不知道作者到底在说哪件事。
- 观点听起来很大，例如“这改变了一切”，但没有说明改变了谁、什么流程、什么结果。
- 文章像直接从最终成文开始生成，没有先经过提纲、材料选择和结构取舍。

处理方向：

1. 先问：这篇文章最想让读者记住哪一句？
2. 再看：每一节是否为这句话提供了故事、证据、反例、解释或推进。
3. 删除只负责“显得重要”的句子，尤其是没有对象、动作和结果的句子。
4. 必要时先把文章压成提纲，调整顺序后再扩写，而不是在原段落里逐句润色。

## 负向定义和判词腔

有些句子问题不在套话，而在“像模型下判词”：先用否定结构框住概念，再给一个抽象名词。它可能逻辑正确，但不像真人会讲。

处理方向：

- 能正着说就正着说，不必保留原来的否定框架。
- 能用动作说清楚，就少用“来源、机制、保证、解释、呈现”这类抽象名词。
- 如果是 `不是 A，而是 B`，先检查 A 和 B 是否都太抽象；如果是，就不要保留这个句式，改写成具体判断。
- 如果原文有锋利判断，可以保留锋利，不要一律改温和。

## 破折号替代

优先避免 `——`。可按语义替换：

- 解释关系：`A——B` -> `A，也就是 B` / `A：B`
- 补充说明：`A——尤其是 B` -> `A，尤其是 B`
- 强转折：拆成两句
- 定义关系：`A——一种 B` -> `A 是一种 B`

## 句子改写法

优先使用这几种手法：

- 删：删掉没有信息量的套话、形容词、连接词。
- 拆：长句拆成两三句。
- 换：抽象词换成具体动作、对象、场景。
- 顺：把句子重心提前，先说结论，再补解释。
- 接：补一句自然过渡，让段落之间有关系。

## 风格边界

不要这样改：

- 不要为了像人写，加入夸张情绪。
- 不要为了顺滑，把事实和条件删空。
- 不要把技术文章改成鸡汤。
- 不要把克制判断改成营销腔。
- 不要改变作者原本立场。

## 最终质感

好的去 AI 味，不是把文章改得更花，而是让它更像一个具体的人在讲清楚一件具体的事：

- 有观点，但不端着。
- 有节奏，但不堆技巧。
- 有温度，但不油。
- 有信息密度，但读起来不费劲。
